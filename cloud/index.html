분석 기준 설정 · ROR / Calmar / Sharpe

시작일의 첫 체결 전 자금을 입력하세요. 이 금액에 이후 실현손익만 더한 모형을 사용합니다. 현재 계좌 기준액을 과거 시작 자금으로 자동 사용하지 않습니다. 입출금이나 미실현손익이 있는 실제 계좌의 수익률·낙폭과는 다릅니다.

지표 계산 기준과 읽는 법
  • EV(R)는 초기 1R이 확인된 종료 거래의 평균 R입니다. PF(R)는 그 표본의 양수 R 합계 ÷ 음수 R 합계 절댓값입니다. PF(USD)는 초기 1R 누락 거래도 포함합니다. 손실이 0이면 숫자 대신 ‘손실 없음’, 손익 모두 0이면 ‘—’를 표시합니다.
  • 승률의 분모에는 본전 거래를 포함합니다. 수수료는 기존 거래 손익에 포함되어 있습니다. R 지표는 보유 중인 거래를 제외하며, 기간 내 종료된 거래의 기간 밖 부분청산도 해당 거래의 전체 결과에 포함합니다.
  • Net Realized와 USD 낙폭은 실제 체결 날짜 기준이며 보유 중인 거래의 부분청산과 진입 수수료도 포함합니다. 종료 R 낙폭은 종료일별 R을 합산한 누적 곡선 기준입니다. 기간 선택 시 고점은 해당 기간 시작점에서 새로 계산합니다.
  • ROR는 모형의 종료 자금 ÷ 기간 시작 자금 − 1입니다. 시작일 이전 손익은 모형에서 제외하고, 필터 시작 이전 손익은 모형의 기간 시작 자금에 반영합니다. Calmar는 CAGR ÷ 일별 최대 낙폭 절댓값이며 365일 이상일 때 표시합니다. 3년 미만은 짧은 관측 기간으로 안내합니다.
  • Sharpe는 일별 수익률에서 일복리 환산 무위험수익률을 뺀 평균 ÷ 일별 수익률의 표본 표준편차 × √365.25입니다. 달력 날짜(주말·휴일 포함)를 사용하고 최소 30일, 양수인 분산이 필요합니다. CAGR도 달력 날짜 기준으로 연환산합니다. 모형 자금이 0 이하가 되면 비율 지표를 표시하지 않습니다.
  • 첨도는 표본 보정 초과첨도입니다. 높은 첨도만으로 좋은 전략이라고 판단할 수 없습니다. 왜도와 분포, 상위 수익 거래를 제외한 손익을 함께 보세요. 30건 미만 표시 기준은 신뢰성 보증이나 매매 신호가 아닙니다.

손실 한도

하루 = 전일 마감 대비 · 주·월 = 기간 시작 직전 마감 대비(없으면 현재 기준액)

미설정 — 이번 주·이번 달 전체 손익으로 셉니다.

손실 한도 빈칸 또는 0은 미설정입니다. 실현손익으로 계산하며 실제 증권사 주문을 차단하지는 않습니다. 포지션당 위험(진입 전 점검·보유 포지션 경고)과 총 오픈 위험(전부 스탑 시 계좌 손실, 계좌 위험 카드 막대)은 빈칸 = 기본값(0.5 / 2 / 6), 0 = 끔.

계산 기준

초기 1R = 최초 실제 진입 수량 × (진입가 − 최초 손절가). 수수료는 실제 지출 시점의 손익에 포함합니다.

부분청산 후 추가매수는 남아 있는 수량에만 새 평균단가를 적용합니다. 과거 실현손익은 바뀌지 않습니다.

모든 날짜와 시각은 미국 동부시간입니다. 전량 청산한 뒤 새로 진입했다면 별도 거래로 기록하세요.
