### 정상 확인 (참고)
- **RLS**: 17개 테이블(+ 이번 backup_log) 모두 `enable row level security`. 앱이 읽는 표의 정책은 전부 `for select to authenticated using (user_id = (select auth.uid()))`
  (hl_fills·hl_funding 은 `address = 내 hl_watch 주소`). 쓰기 정책은 quick_reviews 의 `applied_at, applied_result` 열 update 하나뿐(using + with check 본인).
  kw_collector·hl_pending·acct_hl_*·backup_log 쓰기 = 정책·grant 없음 → security definer 함수로만.
- **실서버 읽기 확인(anon)**: 17개 표 모두 `permission denied`(401), `/storage/v1/bucket` = `[]`, OpenAPI(`/rest/v1/`) 401, GraphQL 비활성,
  `auth/v1/settings` → `disable_signup: true`(가입 막힘), 이메일 로그인만, mailer_autoconfirm false.
  anon 으로 `kw_auth`·`acct_dec`·`kw_status`·`hl_status`·`journal_cas` 호출 → `permission denied for function`; `review_gaps`·`risk_day_data` 는 `invalid collector token`(토큰 검사 동작).
- **security definer 함수 35개**(저장소 SQL 기준, backup_dump 포함): 전부 `set search_path=''` + 완전한 스키마 이름. 내부 함수(kw_auth·kw_reject·kw_check_snapshot·alert_*·hl_collect_tick·acct_* 틱 등)는 `revoke ... from public, anon, authenticated`.
  anon 허용 = 토큰 함수 8개(kw_push·kw_heartbeat·kw_push_balance·risk_status·risk_push·risk_day_data·quick_review_push·review_gaps) + 이번 backup_dump. 모두 첫 줄에서 `kw_auth` → 형식 검사(`^kwc_[A-Za-z0-9_-]{43}$`) → `sha256` 조회 → 분당 60회.
  로그인 함수(journal_cas·journal_restore·kw_*·hl_*·acct_hl_backfill·acct_balance_status)는 `auth.uid()` 없으면 'login required', 본인 행만.
- **토큰 저장**: 브라우저에서 `crypto.getRandomValues` 32바이트 → `kwc_`+base64url, DB 엔 `sha256` hex 만(평문 없음). 한 번만 표시, 재발급 = 이전 토큰 즉시 폐기.
  (sha256 무염 — 256비트 무작위라 무차별 대입 불가, 문제 아님.)
- **크기·횟수 제한**: journal_cas 25 MiB(앱 24 MiB), kw_push 1.5 MB, 스냅샷 행 수 상한, acct_hl_backfill 10분 1회, 토큰 함수 분당 60회.
- **pg_cron**: `hl-collector`(매분) — 등록된 HL 주소로 `https://api.hyperliquid.xyz/info` 공개 조회(userFillsByTime·userFunding)를 pg_net 으로 보내고 응답을 hl_fills·hl_funding 에 적재.
  `acct-balance`(매분, 실제 조회는 UTC 하루 마감 직후) — HL 잔액 → acct_snapshots. URL 하드코딩, 비밀 전송 없음, postgres 권한으로 실행.
- **Storage**: 앱은 Storage 를 쓰지 않음. 차트 사진은 일지 payload 안 `data:image/...;base64`(앱이 형식 검사). 버킷 정책 점검 대상 없음.
- **비밀 노출 검사(git 전체 이력 320 커밋·모든 ref)**: `service_role` 은 "쓰지 마세요" 문구·거부 코드에만. `sb_secret_` = 테스트 더미 `sb_secret_abcdefghijklmnop` 1종(kiwoom-collector/tests, 거부 테스트용).
  JWT(eyJ…) 0, 텔레그램 봇 토큰 패턴 0, `kwc_` 실토큰 0, GitHub PAT·AWS 키·개인키 0. publishable key 조차 저장소에 없음(앱에서 사용자가 입력). env.template 은 자리표시자만.
- **앱**: secret/service_role 키를 넣으면 거부. 서버(trade-alert·kiwoom-collector·backup)도 같은 거부.
